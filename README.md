# Touchline 26/27 ⚽

Manager de fútbol gratis, 100% en el navegador. Sin descargas, sin instalar nada.

**👉 Jugá acá: [touchlineplay.com](https://touchlineplay.com)**

## Qué tiene

- **218 clubes reales** de Europa (Premier League, LaLiga, Serie A, Bundesliga, Ligue 1, Championship) y Sudamérica
- Mercado de fichajes con negociación real (ofertas, contraofertas, cesiones)
- Táctica completa: formación, mentalidad, roles especiales
- Copa Libertadores, Sudamericana, Champions y Europa League
- Guardado automático en la nube — jugá desde cualquier dispositivo, y tené varias carreras a la vez
- Simulación rápida para saltar semanas cuando no querés ver partido por partido

## Cómo jugar

Entrá a [touchlineplay.com](https://touchlineplay.com), creá una cuenta gratis con tu email, elegí un club, y arrancá tu carrera como DT.
